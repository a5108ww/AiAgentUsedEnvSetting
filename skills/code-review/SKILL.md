## 檢查清單

### 1. 命名規範
- 變數：camelCase
- 常數：UPPER_SNAKE_CASE
- 函式：描述性動詞開頭（如 `calculateTotal`）
- 優先使用 `var` 宣告，型別不明確時明確宣告

### 2. 程式風格
- 縮排：參考現有專案風格
- 括號：一致的位置和間距
- 註解：複雜邏輯需要說明

### 3. 程式碼品質
- 避免重複代碼
- 函式長度不超過 50 行
- 參數不超過 3 個
- 避免深度嵌套（>3 層）

### 4. 安全性
- 輸入驗證
- 錯誤處理
- 沒有敏感信息洩露

## 輸出格式

### 📋 問題清單
- [問題類型] 檔案名：具體問題

### ✨ 改進建議
優先級排序：
1. 重要（必改）
2. 建議（可改）
3. 參考（可選）
